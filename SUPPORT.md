# Support

Vibewaiting is an early public alpha for macOS or Linux, Chrome/Chromium/Brave,
and local Claude Code or Codex sessions.

- Use [GitHub Discussions](https://github.com/volter-ai/vibewaiting/discussions) for
  installation help, questions, and design ideas.
- Use the [bug report form](https://github.com/volter-ai/vibewaiting/issues/new?template=bug_report.yml)
  for reproducible defects.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never report them in a public
  issue or discussion.

Before posting, remove credentials, access URLs and codes, private paths, session text,
terminal output, and customer data. Include the Vibewaiting version, operating system,
browser version, harness, and the smallest safe reproduction.

Windows, Firefox, and harnesses other than Claude Code or Codex are not supported in
the current release. The [support matrix](README.md#support-matrix) is the authoritative
capability summary. Community support is best-effort and has no service-level agreement.
