# Support

- Use [GitHub Discussions](https://github.com/volter-ai/vibewaiting/discussions) for
  setup questions, ideas, and usage help.
- Use the bug report form for reproducible defects.
- Use the feature request form for a concrete user problem that fits Vibewaiting's
  browser-companion scope.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never post secrets or private
  session data in an issue or discussion.

This is an early-stage community project. Support is best-effort; there is no service
level agreement.
